# Sixteen Forms — 十六の形

アブストラクト（抽象幾何学）デザインの縦スクロール・シューティングゲーム。全16ステージ。
点・線・面から始まり「原点」へ還る、16の“形”をめぐる旅です。

- **1ファイル完結**：`index.html` だけで動作します（外部ライブラリなし・画像なし・音もすべてWeb Audioで合成）
- **オフライン可**：ダブルクリックでブラウザが開けば遊べます（フォントのみオンライン時に読み込み、オフラインでは等幅フォントで代替）
- **PC / スマホ両対応**：キーボードとタッチ操作
- **進行保存**：到達ステージとハイスコアをブラウザに保存し、タイトルでクリア済みステージから再開可能

## 遊び方

| 操作 | キーボード | タッチ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | ドラッグ（相対移動） |
| ショット | Z / Space（押しっぱなし） | タッチ中は自動連射 |
| 低速移動（当たり判定表示） | Shift / X | — |
| ボム（画面の弾を消去） | C | 右下の BOMB リング |
| ポーズ | P / Esc（ポーズ中 Q でタイトル） | 右上の ‖ |
| サウンド ON/OFF | M | タイトル右上 |

- 当たり判定は自機中央の小さな点だけ。弾をかすめる（GRAZE）とスコア加算。
- 四角いアイテム（P）でショット強化（最大4段階）。画面上部に行くとアイテムを自動回収。
- 各ステージの最後に「核心（ボス）」。IV・VIII・XII・XVI は大型。
- 残機：初期3機、60,000点ほかでエクステンド。ゲームオーバー時はスコアをリセットしてそのステージからコンティニュー可能。

## 配布方法

どれか一つを選んでください。

1. **ファイルをそのまま渡す**：`index.html` を送るだけ。受け取った人はブラウザで開けば遊べます。
2. **ZIPで配布（GitHub Releases）**：`v1.0.0` のようなタグを push すると、GitHub Actions が `sixteen-forms-<タグ>.zip` を作って Release に添付します。
   ```sh
   git tag v1.0.0
   git push origin v1.0.0
   ```
3. **Webで公開（GitHub Pages）**：リポジトリの Settings → Pages で Source を「GitHub Actions」にすると、`main` への push ごとに自動でサイトが公開されます。
4. **itch.io などのゲーム投稿サイト**：上記 ZIP をアップロードし、種類を「HTML」にすれば、ブラウザで遊べるゲームとして公開できます（`index.html` がZIP直下に入っています）。

## Plates — 筋トレプラン & ランク（`plates/index.html`）

同じリポジトリに入っている、筋トレ用の1ファイル完結Webアプリです。ブラウザで開くだけで使えます（記録はブラウザに保存）。

- **週ごとのプランを自動作成**：目標（筋肥大／筋力／減量／健康）・経験・トレーニングする曜日（週2〜6日）・1回の時間（10分〜90分）・重点的に鍛えたい部位・設備（ジム／ダンベル／自重）から、分割法（全身・上下・PPL）と種目・セット・回数・休憩を組み立てます。10分（各種目3セット）と15分（各種目2セット）の短時間メニューも選べます。種目は約70種類から選ばれ、プラン画面で入れ替えもできます。
- **4週間サイクル**：基礎 → 積み上げ → 挑戦（主要種目+1セット）→ ディロード（セット-1・重量90%）。
- **重量の提案**：前回すべて上限回数に届いたら重量アップを提案します。
- **評価システム**：毎回のスコア（100点）とS〜D評価、XPとレベル、競技用プレートの色で表すランク（白5kg→緑→黄→青→赤25kg）、週目標の連続達成、自己ベスト（推定1RM）、16種類のバッジ、部位別の週セット数の目安。
- **Claudeでプラン作成（任意）**：claude.ai の Artifact として開いたときだけ「Claudeに作ってもらう」ボタンが出ます。記録もアカウントに保存されます。

GitHub Pages を有効にしている場合は `/plates/` で公開されます。
